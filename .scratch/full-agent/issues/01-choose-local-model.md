# 01: Выбрать локальную модель

Type: research
Status: resolved
Blocked by: none

## Question

Какая локальная модель в 16 ГБ памяти надёжнее всего гоняет агентный цикл с инструментами?

**What to build:** прогнать `qwen3:4b`, `qwen3:8b`, `qwen2.5-coder:14b` через харнес на одной
и той же задаче (создать мини-приложение из 3 файлов, затем прочитать и поправить один из них).
Сравнить: доля настоящих tool calls против текстового JSON, число итераций до финала,
время ответа, завершила ли задачу. Ответ: модель по умолчанию и почему.

- [x] Таблица сравнения по трём моделям
- [x] Выбрана модель по умолчанию, значение по умолчанию в CLI обновлено
- [x] Отчёт сохранён в `.scratch/full-agent/research/model-choice.md`

## Answer

По умолчанию `qwen3:8b`. Обе qwen3 дали 100% настоящих вызовов инструментов, а 8b быстрее 4b.
`qwen2.5-coder:14b` почти не вызывает инструменты, не подходит.

Оговорка: выборка мала. В одном прогоне `qwen3:8b` заявила, что создала файл, которого нет.
Это аргумент за туман «тюнинг промпта» и за проверку результата в сквозном тикете.
