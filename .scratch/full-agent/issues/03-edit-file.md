# 03: Точечная правка файла

Type: task
Status: resolved
Blocked by: none

**What to build:** агент меняет один фрагмент файла, передавая старый и новый текст, без
перезаписи всего файла. Если старый фрагмент не найден или встречается больше одного раза,
инструмент отказывает с подсказкой, и файл не меняется.

- [x] Замена единственного вхождения меняет только его
- [x] Ноль или два и более вхождений: ошибка, файл не тронут
- [x] Инструмент не выходит за рабочую директорию, как остальные файловые инструменты

## Answer

Инструмент `edit_file(path, old, new)` в `tools.py`. Логика замены в `replace_once`.
- Пустой `old`, ноль или 2+ вхождений, отсутствующий файл: ошибка с подсказкой, файл не тронут.
- Окончания строк (CRLF) сохраняются. `read_file` тоже читает как есть, чтобы фрагмент совпадал.
- Правка в `.git/` и `.venv/` спрашивает подтверждения, как `write_file`.
- Ревью (opus): CRITICAL/HIGH нет. MEDIUM (CRLF) и LOW (подсказка для отсутствующего файла, изоляция теста) исправлены. Атомарная запись отложена.
