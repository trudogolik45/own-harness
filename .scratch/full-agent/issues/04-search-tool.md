# 04: Поиск по коду через rg

Type: task
Status: resolved
Blocked by: none

**What to build:** агент ищет текст или регулярное выражение по проекту и получает список
«файл:строка:текст». Под капотом `rg`. Вывод ограничен числом строк, чтобы не раздувать контекст.
`.venv`, `.git` и прочий мусор не попадают в результаты.

- [x] Поиск по шаблону возвращает совпадения с путём и номером строки
- [x] Нет совпадений: понятный ответ, а не пустая строка
- [x] Результат обрезан по лимиту строк с пометкой, сколько скрыто

## Answer

Инструмент `search(pattern, path=".")` в `tools.py` на `rg`.
- Ответ «файл:строка:текст», сортировка по пути. Больше 50 строк не выдаёт, внизу пометка, сколько скрыто.
- Нет совпадений: `no matches for '<pattern>' in <path>`.
- Пропускает `.git`, `.venv`, скрытые папки и всё из `.gitignore` (git не нужен), файлы больше 1 МБ.
- `--no-config`: личный конфиг rg пользователя не влияет. Шаблон передаётся через `-e`, путь после `--`, поэтому флаг через них не подсунуть.
- Не-UTF-8 и нечитаемые файлы не ломают поиск: совпадения приходят вместе с warning.
- Ревью (opus, затем sonnet): CRITICAL/HIGH исправлены, повторное ревью чистое. Отложено: потоковое чтение огромной выдачи.
