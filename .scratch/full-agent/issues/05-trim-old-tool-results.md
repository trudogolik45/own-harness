# 05: Ужимание старых результатов инструментов

Type: task
Status: resolved
Blocked by: none

**What to build:** после каждой итерации длинные результаты инструментов из прошлых итераций
схлопываются в одну строку вида «результат N символов, скрыт». Свежий результат модель видит
целиком. Так история растёт медленно, и модель не упирается в лимит контекста.

- [x] Результат последней итерации передаётся полностью
- [x] Результаты более старых итераций заменены короткой заглушкой
- [x] Порог длины и глубина «свежести» настраиваются в одном месте

## Answer

`stub_stale_results` в `loop.py` вызывается перед каждым запросом к модели.
- Результаты последних `keep_recent_iterations` итераций (по умолчанию 1) остаются целыми.
- Старые результаты длиннее `stale_result_chars` (по умолчанию 500) заменяются заглушкой «[результат N символов скрыт, вызови инструмент снова, если нужен]». `tool_call_id` сохраняется, формат OpenAI валиден.
- Работает и между ходами REPL. `keep_recent_iterations < 1` запрещён.
- Ревью (sonnet): CRITICAL/HIGH нет. MEDIUM исправлены. Флаги CLI не добавлял, хватает параметров `Agent`.
