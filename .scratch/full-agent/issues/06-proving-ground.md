# 06: Полигон с внедрённым багом

Type: task
Status: resolved
Blocked by: none

**What to build:** отдельная копия `own-harness` с одним понятным багом и падающим тестом,
который его ловит. Плюс короткий сценарий: какой промпт дать агенту и как проверить, что он
справился (тесты зелёные, диф затрагивает только нужное место).

- [x] Копия проекта лежит отдельно и инициализирована как git-репо
- [x] Ровно один тест падает из-за внедрённого бага
- [x] Сценарий проверки записан рядом с полигоном

## Answer

- Скрипт сборки `proving-ground/make.sh`, сценарий `proving-ground/SCENARIO.md`, драйвер без человека `proving-ground/drive.py`. Все три лежат в папке карты, вне полигона, чтобы агент не прочитал ответ.
- Полигон: `../own-harness-proving-ground`. Это маленький проект «магазин» (`shop/`), git-репо, коммит `chore: initial` с тегом `base`.
- Баг: `apply_discount` делит процент на 10 вместо 100. Падает ровно 1 тест из 5. Скрипт сам это проверяет и при неудаче удаляет недособранную копию.
- Первая версия была копией own-harness. Её заменили: qwen3:8b путал код харнеса с кодом проекта (см. «Сквозная проверка: агент чинит баг»).
- Проверка результата: `git diff base --stat`, `git log --oneline base..HEAD`.
