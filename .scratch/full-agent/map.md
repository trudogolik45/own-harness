# Карта: полноценный агент для разработки

Label: wayfinder:map

## Destination

Агент на локальной Ollama в REPL сам чинит баг в проекте: находит код, правит точечно,
гоняет тесты до зелёного, коммитит по просьбе. Проверяется на полигоне: копия `own-harness`
с внедрённым багом.

## Notes

- Домен: харнес = код вокруг LLM; агент = харнес + модель. Глоссарий в `CONTEXT.md`.
- Стек: Python 3.10+, `uv`, `pytest`, `ruff`. TDD: тест → реализация → рефактор.
- Модель: локальная через Ollama, `qwen3:8b` (см. решение по выбору модели).
- Безопасность: shell разрешён, но всё вне белого списка подтверждается «y/N».
- Для себя, не продукт: без полировки, без TUI.
- Тикеты в `.scratch/full-agent/issues/`. Строим прямо в репо, тикет за тикетом.
- Правило: один тикет за сессию (кроме research).

## Decisions so far

<!-- одна строка на закрытый тикет: [название](путь): суть ответа -->

- [Выбрать локальную модель](issues/01-choose-local-model.md): `qwen3:8b` по умолчанию; coder:14b почти не вызывает инструменты; 8b иногда врёт о готовности.
- [Shell-инструмент с белым списком](issues/02-shell-tool.md): белый список по флагам и путям, запуск без shell, остальное через «y/N»; запись теста + pytest — принятый риск.
- [Точечная правка файла](issues/03-edit-file.md): `edit_file(path, old, new)` — ровно одно вхождение, иначе ошибка с подсказкой; CRLF сохраняется.
- [Поиск по коду через rg](issues/04-search-tool.md): `search(pattern, path)` — «файл:строка:текст», лимит 50 строк, уважает .gitignore, без конфига rg.
- [Ужимание старых результатов инструментов](issues/05-trim-old-tool-results.md): свежая итерация целиком, старые результаты >500 символов — заглушка; параметры в `Agent`.
- [Полигон с внедрённым багом](issues/06-proving-ground.md): `../own-harness-proving-ground`, тег `base`, 1 красный тест; сборка `proving-ground/make.sh`, сценарий `proving-ground/SCENARIO.md`. Позже заменён на простой проект «магазин» (см. «Сквозная проверка»).
- [Агент знает правила и не врёт о сделанном](issues/08-agent-knows-the-rules.md): белый список в описании, понятный отказ, порядок работы и честность в промпте, чистое окружение команд, NUDGE; 8b честен, но баг не находит.
- [Сквозная проверка: агент чинит баг](issues/07-end-to-end-bugfix.md): **успех** на простом полигоне «магазин» (qwen3:8b, 8+4 итерации); попутно убрал `round`, тесты не поймали.

## Not yet specified

- Полное сжатие истории моделью (аналог `/compact`), когда ужимания результатов перестанет хватать.
- Сохранение и возобновление сессии между запусками.
- Дисциплина минимальной правки: модель попутно меняет то, что тесты не ловят (убрала `round`). Варианты: тест на округление в полигоне, правило в промпте, проверка дифа.

## Out of scope

- TUI с панелями: не делает агента умнее.
- Субагенты, MCP, слэш-команды, режимы прав как в Claude Code: отдельная карта после этой.
- Внешние провайдеры (Anthropic, OpenAI) как основной режим: остаются доступны через `--base-url`, но не целевой путь.
