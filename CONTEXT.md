# own-harness

Учебный харнес для LLM, который растёт в агента для разработки. Словарь терминов проекта.

## Language

**Харнес**:
Программный код вокруг модели: инструменты, агентный цикл, память, хуки.
_Avoid_: обвязка, оболочка, фреймворк

**Агент**:
Харнес, соединённый с конкретной моделью. Сам по себе харнес ничего не делает.
_Avoid_: бот, ассистент

**Модель**:
LLM: функция «текст на входе, текст на выходе». Локально запущена через Ollama.
_Avoid_: нейронка, лэмка

**Инструмент**:
Действие, которое модель может запросить, а харнес выполнить: чтение файла, поиск, shell.
_Avoid_: тул, тулза, функция

**Агентный цикл**:
Повтор «модель → инструмент → модель», пока модель не ответит без вызова инструментов.
_Avoid_: итерация (это один шаг цикла)

**Память**:
Файлы `AGENTS.md` / `CLAUDE.md`, которые харнес подмешивает в системный промпт каждой сессии.
_Avoid_: контекст проекта, правила

**Хук**:
Обработчик события цикла. Может запретить вызов инструмента, вернув отказ.
_Avoid_: колбэк, middleware

**Белый список**:
Команды shell, которые выполняются без подтверждения пользователя.
_Avoid_: allowlist, safe commands

**Полигон**:
Отдельная копия проекта с внедрённым багом для проверки агента.
_Avoid_: тестовый проект, песочница (sandbox — рабочая директория инструментов)
